# 인하대 후문 점심 뽑기

인하대 후문 근처 점심 메뉴를 룰렛처럼 추천해 주는 단일 HTML 웹앱입니다.

## 바로가기

- 일반 화면: https://mi-ns.github.io/lunch-picker/
- 관리자 화면: https://mi-ns.github.io/lunch-picker/?admin=2195

## 주요 기능

- 여러 식당을 한 번에 랜덤 추천
- 같은 식당이 중복으로 뽑히지 않도록 처리
- 식당 종류, 대표 메뉴, 우선도 기반 추천
- 관리자 화면에서 식당 목록을 표 형태로 편집
- 룰렛 움직임 확률과 고양이 이스터에그 확률 조절
- 모바일에서도 접속 가능한 GitHub Pages 배포

## 관리자 메모

관리자 화면에서 수정한 식당 목록과 설정은 브라우저의 localStorage에 저장됩니다.
다른 기기나 다른 브라우저에도 기본값을 바꾸고 싶다면 `index.html` 안의 기본 데이터를 수정한 뒤 다시 배포해야 합니다.
