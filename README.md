# 인하대 후문 점심 뽑기

오늘 점심 메뉴가 고민될 때, 인하대 후문 근처 식당을 무작위로 추천하는 웹사이트입니다.

**[점심 뽑기 바로가기](https://lunch-picker-opal.vercel.app/)**

## 주요 기능

- 별도 로그인 없이 공용 식당 목록으로 점심 메뉴 추첨
- 음식 종류별 선택 및 최대 6개 식당 추첨
- 그룹별 식당 목록과 추첨 확률 설정
- 고양이, 햄스터, 잭팟 등 이스터에그

## 초대 코드는 왜 필요한가요?

연구실, 친구 모임, 동아리 등 그룹마다 자주 가는 식당과 선호도가 다릅니다. 방을 만들면 각 그룹이 원하는 식당 목록과 추첨 확률을 독립적으로 설정할 수 있습니다.

초대 코드는 그룹별 뽑기 환경과 해당 방의 관리자 페이지를 연결하기 위한 코드입니다. 같은 초대 코드로 입장한 사람들은 동일한 식당 목록과 확률을 사용합니다. 관리자가 설정을 변경하면 해당 방에만 반영되며 공용 목록이나 다른 그룹에는 영향을 주지 않습니다.

공용 점심 뽑기만 이용한다면 초대 코드는 필요하지 않습니다.

## 방 이용 방법

1. 메인 화면의 **방 입장 · 만들기**를 선택합니다.
2. 새 방을 만들 때 방 이름과 관리자 PIN을 정합니다.
3. 생성된 초대 코드를 함께 이용할 사람에게 공유합니다.
4. 참여자는 초대 코드로 입장합니다.
5. 관리자는 **방 관리자**에서 별도 PIN으로 로그인하여 해당 방의 식당 목록과 추첨 확률을 수정할 수 있습니다.

초대 코드는 그룹 참여용이며 관리자 PIN은 설정 변경 권한을 확인하기 위한 별도의 인증 수단입니다. 관리자 PIN은 관리자끼리만 공유하세요.
